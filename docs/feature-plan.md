# QuietGlyph 下一步功能规划

QuietGlyph 以文本编辑为核心，重点是可靠地编辑文件、在多个文件中快速查找内容，以及阅读和处理大文件。以下功能按实施顺序排列。

## 按顺序做

1. **处理文件被外部程序修改的情况。** 文档打开期间发现磁盘内容变化时及时提示。当前文档没有未保存修改，可以重新载入；有未保存修改时，保留编辑内容，让用户选择重新载入或另存。保存时继续检查磁盘文件是否变化，不能静默覆盖。做到用户始终知道编辑中的内容和磁盘内容是否一致。

2. **让工作目录随会话恢复，并能刷新。** 记住上次打开的目录，重启后与已打开的文档一起恢复；为目录树提供刷新，以及从打开文档定位到目录文件的操作。目录被移动或无法访问时提示重新选择。做到用户重启应用或在外部增删文件后，可以继续原来的工作。

3. **补上大文件查找。** 在现有分页查看器中提供上一个、下一个、取消查找和当前位置反馈；目录查找能逐块搜索超过普通文档大小上限的文本文件，不再直接跳过。大文件查找支持普通文本匹配和大小写选项；正则搜索不能覆盖的大文件必须明确标出，不能显示为“无结果”。做到跨读取块、跨编码边界的匹配可以正确定位，同时界面保持可响应。

4. **完善查找结果的使用。** 搜索达到结果上限时显示哪些内容尚未查完；支持导出当前结果。点击结果要定位到正确文件和位置；文件在搜索后变化时提示重新查找。做到用户既能用已有结果继续工作，也不会误以为结果一定完整。

5. **显示文档中的修改行。** 在行号区域标出当前会话修改过且尚未保存的行，撤销、重做和保存后同步更新。沿用现有编辑与撤销行为，不另建一套文档历史。做到标记始终对应当前内容。

6. **整理跳转操作。** 普通文档通过一个入口跳转到行、列或字符偏移量；大文件继续按字节偏移量定位，并在界面上写清单位。做到用户输入位置后能稳定到达目标，不会混淆字符位置与文件字节位置。

7. **支持设置导入和导出。** 覆盖主题、字体、编辑习惯、快捷键和语法样式；导入前检查文件内容，导入后让设置在当前窗口生效。文件路径、未保存内容和恢复记录不放进设置文件。做到用户换一台 Mac 后可以恢复自己的编辑环境，损坏的设置文件不会覆盖现有设置。

8. **加入文件和目录对比。** 对比两个文本文件时展示差异并能跳转到对应位置；对比目录时展示新增、删除和内容不同的文件，并能打开文件处理差异。对比不能修改源文件，只有用户主动编辑或复制内容时才写入。

9. **加入宏录制、保存和执行。** 录制可重复的编辑命令与查找替换操作，保存为可命名的宏，并支持预览执行范围、取消和撤销。宏执行结果要与用户逐步手动操作一致。

10. **处理大文件的编码转换和全文替换。** 在只读查看之外，提供针对大文件的独立处理流程：预览目标、逐块处理、写入新文件，并在成功后由用户决定是否替换原文件。处理中断或磁盘空间不足时，原文件保持完整。

11. **实现超大文本文件编辑。** 支持数 GB 文件的局部修改、撤销、保存和异常退出恢复，不把整个文件装进普通文档编辑器。先确定文件数据、临时空间与修改记录的管理方式，再把编辑入口开放给用户。

12. **加入十六进制编辑。** 在现有只读十六进制查看上支持字节修改、插入和删除，并提供撤销、地址跳转及安全保存。保存前明确显示文件大小变化，避免误改二进制文件。

13. **建立插件和脚本扩展能力。** 定义插件可调用的文档、选区、命令和菜单接口，提供安装、启停和权限提示，再加入脚本运行能力。已有内置功能继续可用，插件异常不能损坏正在编辑的文档。

14. **支持 FTP 远程文件。** 在插件能力之上提供远程连接、浏览、下载、编辑后上传和冲突处理。网络断开时保留本地修改，重新连接后由用户确认上传。

15. **加入 PDF 工具。** 通过独立工具或插件提供合并、拆分、旋转、加密、解密和水印等操作，与文本编辑区分入口。每次处理输出新文件，避免覆盖原 PDF。

16. **推出其他桌面平台版本。** 在 macOS 功能和数据格式稳定后，确定 Windows、Linux、鸿蒙 PC 等目标平台的实现方式，保留文档格式、设置和常用操作的一致性；各平台使用符合自身习惯的界面与快捷键。
